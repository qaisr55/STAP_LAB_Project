# STAP Lab – End Semester Project

## 📌 Project Overview

This repository contains my **Statistical Techniques and Applications in Python (STAP) Lab End Semester Project**.

The project focuses on analyzing a Sales and Marketing Customer Dataset using Python and various data analysis and statistical techniques.

The main objective is to understand customer behavior, clean and process raw data, perform statistical analysis, visualize important patterns, and explore relationships between different customer-related variables.

## 🎯 Project Objectives

- Understand the structure and characteristics of the dataset.
- Identify and handle missing values.
- Detect and handle outliers using the IQR method.
- Perform descriptive statistical analysis.
- Create meaningful data visualizations.
- Apply probability distributions.
- Perform correlation analysis.
- Build a Linear Regression model to explore the relationship between marketing expenditure and customer lifetime value.
